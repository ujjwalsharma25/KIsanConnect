# KisanConnect — data used (3 sources, all free)

| File | What it is | Rows | Date range | Used for |
|---|---|---|---|---|
| `commodity_price.csv` | Kaggle "Daily Wholesale Commodity Prices – India Mandis" (Agmarknet). Mandi-level: state, district, market, variety, grade, min/max/modal price | 2,733 | **one day: 19 May 2025** | Trains the AI Fair Price model, state comparison, cheapest/costliest mandis |
| `national_snapshot.json` | Official Agmarknet *Marketwise Price & Arrival Report* (downloaded 04 Oct 2026): national price + arrivals for 25 crops, last 3 days, plus MSP 2026-27 | 25 crops × 3 days | 30 Sep – 02 Oct 2026 | MSP check, "Sell now or wait?" advisor, today's national benchmark, savings simulator |
| `onion_history_summary.json` | Summary built from the open GitHub dataset `amitkaps/onions-dataset` (daily onion mandi prices + arrivals) | 30,959 | 01 Jan 2020 – 29 Jul 2022 | Onion seasonality context in the advisor |
| `mandi_clean.json` | Cleaned version of `commodity_price.csv` (auto-generated by `ml-service/train.py`) | – | – | Dashboards |

## Honest limitations
- The model is trained on a **single-day** mandi snapshot (May 2025) -> it estimates a *fair rate*, it does **not** forecast.
- The 2026 official report is **national-level** (not per mandi), so it is shown *next to* the AI estimate, never blended into it.
- The "Sell now or wait?" signal uses only 3 days of data + simple transparent rules. It is a signal, not a prediction.
- Onion history is 2020-22 (old) and only used as context; Oct→Nov moved +5.6% in 2020 and −19.6% in 2021 — no consistent pattern, and the app says so.
- Escrow is simulated (no payment gateway) — see README for the upgrade path.

## Refresh the data
1. Replace `commodity_price.csv` with a newer/multi-day export and run `cd ml-service && python train.py`.
2. For the national report: Agmarknet -> *Marketwise Price & Arrival Report* -> download CSV, then re-create `national_snapshot.json` (same keys: `dates`, `crops{price[3], arrival_mt[3], msp}`).
